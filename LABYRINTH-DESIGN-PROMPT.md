## Концепция «Лабиринта Бездны» (придумай и разверни детальнее)

Отправная точка, которую нужно развить в полноценный дизайн-документ:

- **Жанр:** рогалик-данжен-кроулер с процедурно генерируемыми этажами.
  Игрок спускается всё глубже в Бездну — чем глубже, тем страшнее и ценнее
  награды.
- **Сюжетный крюк:** Бездна зовёт Seeker'ов, готовых рискнуть (вписывается в
  лор Genesis Pre-Season / Founder). Смерть не уничтожает весь прогресс
  полностью (не хардкорный permadeath) — но забирает несобранные
  на этом забеге релики, оставляя базовый ORB и опыт. Это снижает фрустрацию
  для казуальной mobile-аудитории, но сохраняет напряжение рогалика.
- **Основной цикл:** этаж → навигация по лабиринту в тумане войны (свет
  факела ограничивает видимость) → встречи (тени-монстры, ловушки, сундуки
  с реликвиями) → лестница на следующий этаж или "Страж" (мини-босс) каждые
  N этажей → смерть или добровольный выход с сохранением награды.
- **Прогрессия между забегами:** постоянные апгрейды за ORB — радиус света
  факела, скорость передвижения, доп. слот реликвии, страховка от одной
  смерти за забег (аналог существующих Streak Shields). Структура апгрейдов
  должна повторять существующий паттерн `UPGRADE_DEFS` (5 уровней, растущая
  стоимость, явный "NOW → NEXT").
- **Лидерборд:** глубина максимального спуска — интегрируется в существующую
  систему Tournament/leaderboard через `onAddTournamentScore`.
- **SOL-точки монетизации** (по образцу остальных игр, не выдумывай новые
  механики оплаты): платное продолжение забега после смерти (сохранить
  реликвии этого захода), разовая покупка редкого светильника/скина.

Ты волен(на) углубить лор, придумать 3–5 типов теней-врагов, 4–6 типов
реликвий с эффектами, визуальный стиль стражей-боссов — но всё должно
оставаться реализуемым в 2D top-down/изометрическом виде средствами RN
(Animated/SVG/PNG-спрайты), без 3D-движка.

## Что конкретно должно войти в результат — 5 столпов AAA-полировки

1. **Дизайн-система** для этой игры как расширение текущей темы: палитра
   света/тени (динамический радиус видимости, bloom/glow вокруг источников
   света), типографика (крупный "боевой" шрифт для урона/наград, читаемый
   HUD), сетка отступов, состояния карточек реликвий (обычная/редкая/эпичная
   — по аналогии с существующими tier-бейджами BASIC/RARE/EPIC/LEGEND в шопе).
2. **Movement & feel:** свайп-жесты для перемещения по лабиринту.
   Порекомендуй добавить `react-native-reanimated` +
   `react-native-gesture-handler` именно для этого компонента (их сейчас
   нет в проекте) — для отзывчивого 60fps управления вместо JS-driven
   Animated API. Опиши, почему это оправдано именно здесь.
3. **Juice:** экранный шейк при уроне, частицы при подборе реликвий (через
   существующий `ParticleEmitter`), плавные переходы между этажами
   (fade-to-black + факел разгорается), пульсация HUD при низком здоровье,
   haptic feedback (`expo-haptics`) на попадания и находки.
4. **Атмосфера и свет:** туман войны, динамические тени, парящие частицы
   пыли, глубина через параллакс слоёв фона — сделай так, чтобы даже
   статичный скриншот выглядел как промо-арт AAA-игры.
5. **Экран за экраном:** вход в лабиринт (превью прогресса, кнопка "спуск"),
   игровой HUD (здоровье, этаж, реликвии, мини-карта), находка реликвии
   (полноэкранный reveal), встреча со Стражем, экран смерти/выхода
   (сводка забега + предложение платного продолжения), таблица лидеров
   по глубине.

## Технический контракт для интеграции (соблюдай для последующей сборки)

Сделай новый компонент по образцу существующих мини-игр
(`components/TreasureHunt.tsx`, `components/Arena.tsx`,
`components/SpaceRunner.tsx`) — они получают экономику через пропсы, а не
управляют ею сами:

```tsx
type LabyrinthProps = {
  deviceId: string;
  username: string;
  orb: number;
  onEarnOrb: (n: number) => void;
  onSpendOrb: (n: number) => void;
  onAddTournamentScore: (n: number) => void;
  onPaySol?: (lamports: number, sol: number, purpose: string) => Promise<void>;
  onPlaySound: (sound: 'tap' | 'crit' | 'jackpot' | 'levelup' | 'dead') => void;
  onExit: () => void;
};
export default function LabyrinthOfAbyss(props: LabyrinthProps) { /* ... */ }
```

Расширяй интерфейс своими полями (например `onFloorCleared`), но сохрани
базовый контракт — так игру можно будет подключить в `App.tsx` одной
строкой, как остальные.
